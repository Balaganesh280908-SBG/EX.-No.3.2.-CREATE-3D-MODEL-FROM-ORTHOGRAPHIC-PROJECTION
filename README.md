# EX No.3.2. CREATE 3D MODEL FROM ORTHOGRAPHIC PROJECTION
## DATE:
## AIM:
To create a 3D model from given orthographic projection.

## REQUIREMENTS:
1. Autodesk fusion 360
2. Windows 10
3. 16 GB of RAM (integrated graphics recommend 1 GB or more)
4. 2.5 Mbps or faster download; 500 Kbps or faster upload 

## PROCEDURE:

## Step 1 
     1. Draw a circle of diameter 220 mm with the origin as its centre.
     2. Draw a line through the centre of the circle. 
     3. Draw a rectangle of dimension 120 mm. 
     4. Trim the excess parts.
     5. Extrude it to 150 mm.

## Step 2
    1. Go to Construct, select Offset Plane and choose the top plane (XZ). 
    2. Select the newly created plane and create a sketch. 
    3. Draw the outer outline of the base plate with an overall length of 420 mm, a corner radius of 60 mm and a total width of 150 mm.

## Step 3
     1. Finish the sketch and select Extrude. 
     2. Select the base profile.
     3. Extrude it upward to a thickness of 30 mm.
     4. Set the operation to Join.

<img width="200" height="100" alt="image" src="https://github.com/user-attachments/assets/b3ad568a-4adb-4e1a-a390-fe34a783e8e5" />

## Step 4
     1. Select the top surface and create a sketch. 
     2. Draw circles of diameter 40 mm, concentric with the centres of the R60 rounded arcs at both ends of the flange.
     3. Finish the sketch and select Extrude.
     4. Select both circles and set the operation to Cut. 
     5. Set the extent to All so that the holes cut completely through the 30 mm base flange.

<img width="237" height="341" alt="image" src="https://github.com/user-attachments/assets/416dbd04-0001-4160-95cc-222c7205b82e" />

## Step 5
     1. Select the top surface and draw a circle of diameter 20 mm at the centre. 
     2. Finish the sketch and extrude it by -20 mm. 
     3. Select Design → Drawing → From Design.
     4. Place the front view and side view on the sheet.
